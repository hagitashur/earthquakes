# רעידות אדמה – ריפו תרגול

> **זהו ריפו תרגול.** הוא נבנה במסגרת מטלת בונוס בקורס הטמעת AI בארגונים, ואינו מוצר או שירות.

## מה זה
דשבורד בעברית שמציג את רעידות האדמה בעולם ב-30 הימים האחרונים, בעוצמה 4.0 ומעלה: סיכום, גרף לפי טווחי עוצמה, מפה וטבלה.

## מקורות מידע
נתוני הרעידות מ-API ציבורי של USGS, ושמות המדינות בעברית מ-REST Countries. פירוט ב-`SOURCES.md`.

## מבנה הריפו
- `index.html` – הדשבורד
- `scripts/fetch_quakes.py` – שליפת הנתונים
- `.github/workflows/fetch-quakes.yml` – הרצת השליפה בגיטהאב
- `data/` – הנתונים שנשלפו (נוצר בהרצה)
- `docs/SPEC.md` – אפיון, `docs/PLAN.md` – תוכנית עבודה, `docs/CHANGELOG.md` – יומן שינויים
- `SOURCES.md` – מקורות

## איך מפעילים
1. בגיטהאב: לשונית **Actions** → **fetch-quakes** → **Run workflow**.
2. אחרי שההרצה מסתיימת, קובץ `data/quakes.js` מופיע בריפו.
3. פותחים את `index.html` בדפדפן (או דרך GitHub Pages).

## מצב נוכחי
השליפה מ-USGS עובדת ונבדקה מול המקור. זיהוי המדינה בעברית כרגע לא פעיל. פירוט ב-`docs/CHANGELOG.md`.

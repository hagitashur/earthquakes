# רעידות אדמה – ריפו תרגול

> **זהו ריפו תרגול.** הוא נבנה במסגרת מטלת בונוס בקורס הטמעת AI בארגונים, ואינו מוצר או שירות.

## מה זה
דשבורד בעברית שמציג את רעידות האדמה בעולם ב-30 הימים האחרונים, בעוצמה 4.0 ומעלה: סיכום, גרף לפי טווחי עוצמה, מפה וטבלה.

## מקורות מידע
נתוני הרעידות מ-API ציבורי של USGS. שמות המקומות נשארים באנגלית, כפי שמגיעים מהמקור. פירוט ב-`SOURCES.md`.

## מבנה הריפו
- `index.html` – הדשבורד
- `scripts/fetch_quakes.py` – שליפת הנתונים
- `.github/workflows/fetch-quakes.yml` – הרצת השליפה בגיטהאב
- `data/` – הנתונים שנשלפו (נוצר בהרצה)
- `docs/SPEC.md` – אפיון, `docs/PLAN.md` – תוכנית עבודה, `docs/CHANGELOG.md` – יומן שינויים
- `SOURCES.md` – מקורות

## עדכון הנתונים
הנתונים מתעדכנים **אוטומטית פעם ביום** (03:17 UTC, כ-06:17 שעון ישראל בקיץ). אפשר גם להריץ ידנית: לשונית **Actions** → **fetch-quakes** → **Run workflow**.

## צפייה
הדשבורד חי ב-GitHub Pages: https://hagitashur.github.io/earthquakes/ (או פותחים את `index.html` מקומית).

## מצב נוכחי
השליפה מ-USGS עובדת ונבדקה מול המקור. פירוט ב-`docs/CHANGELOG.md`.

# תוכנית עבודה: דשבורד רעידות אדמה

## 1. התוצאה שנראה בדשבורד
דף HTML אחד, בעברית, שנפתח בדפדפן ומציג:
1. **סיכום:** כמה רעידות היו בשנה האחרונה, כמה מעל 4, כמה מתחת ל-4, וכמה בדיוק 4.0.
2. **רשימה:** כל הרעידות, עם תאריך, מיקום ועוצמה.
3. **מפה:** נקודה לכל רעידה, בצבע לפי עוצמה.
4. **גרף:** שכיחות לפי טווחי עוצמה.

## 2. כלים ודרישות, לפי התוצאה
| צורך | כלי | סטטוס |
|---|---|---|
| שליפת נתונים | פייתון (urllib, ללא ספריות חיצוניות) | מוכן |
| עיבוד וספירה | פייתון | מוכן |
| גרף | Chart.js מ-CDN | מאושר |
| מפה | Leaflet + OpenStreetMap | מאושר |
| מדינה לכל רעידה | REST Countries | מאושר |
| ריפו ציבורי | GitHub + git | **חסום**: הסשן לא יכול ליצור ריפו חדש, נדרשת יצירה ידנית |
| קובץ מקורות | `SOURCES.md` | לכתיבה |
| יומן שינויים | `CHANGELOG.md` | נכתב |

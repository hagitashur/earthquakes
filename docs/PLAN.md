# תוכנית עבודה: דשבורד רעידות אדמה

## 1. התוצאה שנראה בדשבורד
דף HTML אחד, בעברית, עם רקע חום בהיר, שמציג את 30 הימים האחרונים:
1. **סיכום:** כמה רעידות בעוצמה 4 ומעלה, העוצמה החזקה ביותר, וכמה בעוצמה 5 ומעלה.
2. **גרף:** כמה רעידות בכל טווח עוצמה.
3. **מפה:** נקודה לכל רעידה, בצבע לפי עוצמה.
4. **טבלה:** כל הרעידות, עם מדינה ומיקום.

## 2. כלים, לפי התוצאה
| צורך | כלי | סטטוס |
|---|---|---|
| שליפת רעידות | USGS API, פייתון (ספריות סטנדרטיות) | נכתב, **טרם הורץ על נתונים אמיתיים** |
| שם מדינה בעברית | REST Countries | נכתב, **טרם הורץ** |
| גרף | Chart.js 4.4.1 (CDN) | נבדק על נתוני בדיקה |
| מפה | Leaflet 1.9.4 + OpenStreetMap | נבדק על נתוני בדיקה (בלי אריחי מפה) |
| הרצת השליפה | GitHub Actions | נכתב, טרם הופעל |
| ריפו | `hagitashur/earthquakes` (ציבורי) | נוצר ומחובר |

## 4. מה לא נבדק עדיין
- הסקריפט לא רץ מעולם מול USGS ומול REST Countries האמיתיים. הוא נבדק רק על קובץ בדיקה.
- ייתכן ש-REST Countries ישנה שדות או מגבלות, ואז הזיהוי ייכשל.
- מספר הרעידות החודשי לא נבדק מול המגבלה של 20,000.
